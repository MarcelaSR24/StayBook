# INFORME DE CALIDAD – STAYBOOK

## 1. Objetivo

Establecer los criterios y actividades para evaluar la calidad de StayBook, verificando que sus funcionalidades cumplan los requisitos establecidos y que la aplicación funcione correctamente.

## 2. Alcance

La evaluación de calidad comprende:

- Registro e inicio de sesión de usuarios.
- Consulta y gestión de alojamientos.
- Registro, consulta y cancelación de reservas.
- Cálculo de precios y validación de disponibilidad.
- Seguridad y control de acceso.
- Integridad de los datos.
- Usabilidad y adaptación de la interfaz.

## 3. Criterios de calidad

| Criterio | Condición de evaluación |
|---|---|
| Funcionalidad | Las operaciones principales deben cumplir los requisitos. |
| Usabilidad | La aplicación debe ser comprensible y fácil de utilizar. |
| Seguridad | Las operaciones protegidas deben requerir autenticación. |
| Integridad | Los datos deben conservar sus relaciones correctamente. |
| Validación | El sistema debe rechazar datos que no cumplan las reglas establecidas. |
| Compatibilidad | La aplicación debe visualizarse correctamente en navegadores modernos. |
| Mantenibilidad | El código debe conservar una estructura organizada. |

## 4. Actividades de calidad

Para evaluar y mejorar la calidad del proyecto se contemplan las siguientes actividades:

1. Revisar la organización del código fuente.
2. Verificar los formularios y sus validaciones.
3. Ejecutar pruebas funcionales y no funcionales.
4. Comprobar la seguridad y las relaciones de los datos.
5. Registrar los errores encontrados y realizar las correcciones necesarias.
6. Conservar las evidencias de las verificaciones realizadas.

## 5. Estado de la calidad del proyecto

Durante el proceso de verificación se han realizado comprobaciones relacionadas con el funcionamiento de los alojamientos, la autenticación, la integridad de los datos, las validaciones y la presentación de la aplicación.

También se han identificado aspectos que requieren verificaciones adicionales, como la comprobación completa del almacenamiento seguro de contraseñas y algunas pruebas de compatibilidad.

Los resultados se clasifican de la siguiente manera:

- **Aprobada:** la verificación cumple lo esperado.
- **Aprobada parcialmente:** se ha comprobado una parte, pero falta completar la verificación.
- **Pendiente:** falta realizar o confirmar la prueba o su evidencia.

Los aspectos pendientes continuarán revisándose durante las siguientes etapas del proyecto. No se consideran aprobados hasta contar con la verificación correspondiente.

El proceso de pruebas continuará para completar las comprobaciones pendientes, corregir posibles defectos y reunir las evidencias necesarias para evaluar el cumplimiento de los requisitos del proyecto.
