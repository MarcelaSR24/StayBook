# StayBook

Plataforma web de gestión y reservas de alojamientos desarrollada con Laravel, PHP, Blade, Bootstrap y MySQL.

# Descripción

StayBook permitirá gestionar alojamientos y administrar sus reservas mediante una aplicación web.

# Tecnologías

- Laravel 13
- PHP 8.3
- Blade
- Bootstrap
- MySQL
- Git y GitHub
